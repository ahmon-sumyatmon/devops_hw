# DevOps Homework

DevOps သင်ခန်းစာများအတွက် အိမ်စာနှင့် လေ့လာရေးမှတ်စုများကို သိမ်းဆည်းထားသော repository ဖြစ်သည်။

## Git Homework

မြန်မာဘာသာဖြင့် ရေးသားထားပြီး လက်တွေ့ command၊ commit diagrams၊ conflict ဖြေရှင်းနည်းပါဝင်သည်။

ပါဝင်သော ခေါင်းစဉ်များ:

1. Different Types of Merge Strategies — merge strategies နှင့် merge methods ကွာခြားချက်
2. Cheatsheet for Git Branching — branch ဖန်တီးခြင်း၊ ပြောင်းခြင်းနှင့် နှိုင်းယှဉ်ခြင်း
3. Cheatsheet for Time Travel — အတိတ် commit ကြည့်ခြင်း၊ restore၊ reset၊ revert နှင့် reflog
4. Cheatsheet for Rebase vs Merge — history ကွာခြားချက်၊ conflict ဖြေရှင်းခြင်းနှင့် interactive rebase
